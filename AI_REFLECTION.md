# Programming Decisions
One important decision was to check the BMI inputs before calculating the result. This prevents the program from calculating BMI when the weight or height is zero or negative. In the Color Mixer program, I used strcmp to compare the color names because the assignment requires character arrays instead of strings. I also checked whether both colors were valid before deciding which color to display.

# Checking My Work
I planned tests for normal BMI values, invalid measurements, different color combinations, identical colors, and invalid color names. For example, I expected a weight of 150 pounds and a height of 70 inches to produce a BMI of 21.52 and the category Optimal weight. I also expected red and blue to produce purple, regardless of their input order. I used these expected results to check the programs against their actual output.
